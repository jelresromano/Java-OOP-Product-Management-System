# Java OOP Product Management System

## 📌 About the Project

This project is a simple **Product Management System** developed in Java to demonstrate fundamental Object-Oriented Programming (OOP) concepts. It manages different types of products, specifically groceries and transportation, by displaying their information and calculating their total prices based on quantity.

## 🚀 Features

- **Product Management** – Stores product names and prices.
- **Grocery Class** – Includes expiry date information.
- **Transportation Class** – Includes speed, year model, capacity, and availability.
- **Total Price Calculation** – Computes the total amount based on the product price and quantity.
- **Object-Oriented Programming** – Demonstrates inheritance and encapsulation using classes, constructors, getters, and setters.

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)

## 💻 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Java-OOP-Product-Management-System.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Java-OOP-Product-Management-System
   ```

3. Compile the Java files:

   ```bash
   javac Main.java Product.java Grocery.java Transportation.java
   ```

4. Run the program:

   ```bash
   java Main
   ```

## 📖 OOP Concepts Demonstrated

| Concept | Description |
|---|---|
| Inheritance | `Grocery` and `Transportation` extend the `Product` class. |
| Encapsulation | Private fields are accessed and modified through getters and setters. |
| Constructors | Initialize product details when objects are created. |
| Methods | Display product information and calculate total prices. |

## 🎯 Learning Objectives

- Understand how inheritance works in Java.
- Practice encapsulation using private fields and public methods.
- Create and initialize objects using constructors.
- Apply methods to display information and perform calculations.
